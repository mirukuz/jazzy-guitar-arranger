# Jazzy Guitar Arranger

A Codex skill for creating playable, harmonically rich guitar arrangements and explaining arrangement choices. It can also analyze and annotate guitar scores with clear labels for the underlying chords, reharmonizations, and passing harmony.

## Install

Copy this repository folder into your Codex skills directory:

- macOS/Linux: `~/.codex/skills/neo-soul-guitar-arranger/`

The folder should contain `SKILL.md` and the `agents/openai.yaml` metadata file. Restart or refresh Codex if the skill does not appear immediately.

## Use

Ask for a playable guitar arrangement, an explanation of a chord or voicing choice, or red-pen analysis of a supplied guitar score. Provide the song version or score when the harmony is uncertain.
